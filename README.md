## Overview

Preparing for the AWS Certified Cloud Practitioner CLF-C02 exam requires familiarity with a broad range of AWS services. AWS Cloud Practitioner Flashcards provides a compact way to review more than 95 services arranged into 12 service categories, helping learners connect each service with its primary function.

Practice works in both directions: start with a service description and identify the matching service, or view a service name and recall what it is used for. Sessions can be narrowed to specific categories, scored as you go, and repeated with missed cards. Shuffle and restart controls support additional practice, while a separate single-page visual guide offers a quick summary of the eight exam domains.

## How to Study

1. Launch the HTML file in a web browser.
2. Select a category, or keep the full card collection enabled.
3. Pick a practice direction:
   - **Name to function** - determine the purpose of the displayed AWS service.
   - **Function to name** - identify the AWS service described by the card.
4. Reveal each card and submit your answer.
5. Check your score at the end of the session.
6. Practice missed cards again or begin a new shuffled session.
7. Use the visual guide when you want a brief overview of the eight exam domains.

Yes. Choose the relevant categories before starting a session to review only selected service groups.
